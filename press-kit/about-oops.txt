100 words

oops! web studio, also known as oopsweb, is a creative web design studio making wildly interactive 3D websites, beautifully minimal sites, launch pages and web games. Founded in 2026 and based in Gandhinagar, Gujarat, India, the studio has made 20 product sites and 3 web games, all self-initiated studio projects. The games include Whereabouts, a free daily detective game set in a 3D dolls' house. On Monday 23 November 2026 the studio will launch Spot the Oops, a free one-minute daily game in which each round is a working interface with one real design problem to find. Happy accidents happen.
